Dusk Differences — a complete spot-the-difference game: three original hand-drawn scenes (a dusk coffee stall, a morning market, a dusk park), 22 differences to find, ring markers on both pictures, a counter of what remains, hints, a countdown, score with combos and stars. Runs offline in a desktop browser from static files, no network request.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
